# Slider

7x7 보드에서 타일을 타고 미끄러져 중앙(골)에 먼저 멈추는 쪽이 이기는 콘솔 게임입니다.
플레이어(P)와 AI(E)가 번갈아 둡니다.

## 규칙

- 보드: 7x7, 타일(■) 12개가 네 귀퉁이에 3개씩 있습니다. 플레이어는 (0,6), AI는 (6,0)에서 시작하고 골(G)은 (3,3)입니다.
- 한 턴에 `w`(위) `a`(왼쪽) `s`(아래) `d`(오른쪽)를 입력합니다.
  - 옆 칸이 타일이면 그 타일로 **걸어갑니다**. 턴은 계속됩니다.
  - 옆 칸이 빈 칸이면 서 있는 타일째 그 방향으로 **미끄러집니다**. 다른 타일이나 벽 바로 앞에서 멈추고 턴이 끝납니다.
  - 상대가 있는 칸으로는 갈 수 없습니다.
- 골에 정확히 멈추면 이깁니다. 미끄러짐은 타일/벽 앞에서만 멈추므로, 골 건너편에 **받침 타일**이 있어야 합니다.
- 플레이어가 먼저 둡니다.

## 실행

```bash
mvn compile
java -cp target/classes org.example.Main
```

테스트:

```bash
mvn test
```
