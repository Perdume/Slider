# Slider 학습 앱 (Android)

폰에서 신경망 학습(자가대전 → 학습 → 대국 확인 → 채택)을 돌리는 앱입니다. 실제 계산은 `rust/` 의 Rust 실행 파일(arm64)이 하고,
앱은 그걸 포그라운드 서비스로 띄워서 로그를 보여 주고 결과를 다운로드 폴더에 저장하는 얇은 껍데기입니다.

## 설치와 사용
1. `slider-train.apk` 를 폰에 옮겨서 설치합니다 (출처를 알 수 없는 앱 설치 허용 필요, 디버그 키로 서명됨).
2. 앱을 열고 설정을 확인한 뒤 **시작**. 화면을 꺼도 계속 돕니다 (포그라운드 서비스 + CPU 깨어 있음 유지).
3. 끝나면(또는 중지 후) **결과를 다운로드 폴더에 저장** → `slider_net_*.txt` 가 Download 폴더에 생깁니다.
   그 파일을 PC로 옮겨서 `matchup --net-a net.txt ...` 로 쓰면 됩니다 (`rust/README.md` 참고).
4. 선형 가중치(`weights.json`)가 있으면 입력란에 내용을 붙여 넣으세요. 비우면 기본 가중치입니다.

기본 설정(600판 × 2라운드)은 폰 코어 수와 발열에 따라 시간이 많이 걸립니다. 먼저 판 수를 줄여서(예: 100판, 1라운드) 한 번 돌려 보세요.
폰이 뜨거워지면 스레드 수를 줄이세요. 학습 결과는 대국 점수 0.55 이상일 때만 채택되고, 아니면 "채택된 신경망이 없습니다"가 나옵니다.

## NPU / GPU 를 쓰지 않는 이유
- 시간의 대부분은 **탐색**(비트보드 이동 생성과 알파베타)이고, 정수 연산과 분기가 많아서 NPU/GPU 에 올릴 수 없습니다.
- 신경망은 파라미터가 4,800개 남짓인 아주 작은 모델이라 학습 비용이 거의 없습니다 (로컬에서 3만 국면 40 epoch 이 1초 정도).
- 안드로이드 NPU 는 추론용이고 학습을 지원하는 공개 경로가 없습니다 (NNAPI 도 폐기 예정).

그래서 이 앱은 CPU 코어를 전부 쓰는 쪽으로 최적화했습니다 (스레드 수 조절, 수당 시간 조절, 중지 시 한 판 단위로 깨끗하게 멈춤).

## 빌드
```bash
sdkmanager "platforms;android-34" "build-tools;34.0.0" "ndk;26.3.11579264"
ANDROID_HOME=/path/to/sdk ./build_apk.sh      # 결과: build/slider-train.apk
```
Gradle 을 쓰지 않고 SDK 도구(aapt2, d8, zipalign, apksigner)만 씁니다. 실행 파일은 `lib/arm64-v8a/lib*.so` 로 APK 에 들어가고
(`extractNativeLibs=true`), 설치 때 앱의 네이티브 폴더에 풀려서 거기서 실행됩니다.

## 확인한 것과 못 한 것
- 확인: APK 서명/정렬/매니페스트, 안에 든 파일, 같은 `trainloop` 을 x86 에서 정상 실행·중지·부모 강제 종료까지 시험.
- **못 한 것: 실제 안드로이드 기기나 에뮬레이터에서의 설치와 실행.** 이 환경에는 기기가 없어서 앱 화면, 권한 팝업, 포그라운드 서비스,
  네이티브 폴더에서의 실행(기기 제조사/SELinux 설정에 따라 막힐 수 있음)은 직접 확인하지 못했습니다.
  실행이 막히면 로그에 `실행할 수 없습니다 ... Permission denied` 같은 줄이 나옵니다.
