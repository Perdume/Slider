# 새 규칙(순환) 연구 기록

규칙: 대각선 배치, 말 하나씩 시계 방향 (나 1 → AI X → 나 2 → AI Y).
대국은 모두 VM 에서 30ms/수, 1스레드, SPRT [0, 25] (따로 적은 것 제외). Elo 는 A 쪽 기준, 괄호는 95% 범위.

## 1. 예전 규칙 튜닝이 새 규칙에서도 통하는가 (기준: 예전 게임 설정)

| 실험 | 결과 | 판정 |
|---|---|---|
| 튜닝 가중치 vs 기본 가중치 | 148승 15무 81패, Elo +98 | 통과 |
| SPSA 상수 vs 기본 상수 | 95승 0무 47패, Elo +122 | 통과 |
| lmr2 vs 탐색 개선 없음 | 110승 20무 64패, Elo +84 | 통과 |
| 함정 보너스 끔 | 347승 91무 364패, Elo -7 | 기각 |

- 무승부: 0~11% (예전 규칙 약 70%). 엔진 자가대전 2000판 기준 2.5%.
- Texel (판 결과 맞히기로 가중치 맞추기): 33만 국면에서 정적 평가와 결과의 상관 0.007, 탐색 점수도 0.05 → 쓸모없음
  (엔진끼리의 판은 막판 전술로 갈려서 중반 국면만으로는 승패를 알 수 없음). 가중치는 대국 결과로 맞추는 SPSA 로.

## 11. 평가 신경망 (탐색 점수로 학습, 11/04 아침)
- 신경망 입력에 순환 규칙 정보 추가: 타일 / 내 말 / 상대 말 + **지금 움직일 내 말(mc)**, **상대가 다음에 움직일 말(oc)** (245개) + 선형 특징 11개 -> 은닉 32.
  평가 = 선형 평가(+ nt 요소) + 신경망 출력. 목표는 판 결과가 아니라 엔진 탐색 점수 (λ=1).
- 1차: 어제 저녁 엔진 판 34만 국면 (30ms, 당시 기본 상수라 nt 요소 없음). 탐색 점수 맞히기 오차 0.0172 -> 0.0030 (-82%) 이었지만
  대국은 **0승 20패**. 진단: 그때 탐색 점수는 ±50 정도인데 지금 정적 평가는 ±300 (nt 688 등) 이라, 신경망이 선형 평가를 거의 지우는 쪽으로 배움
  (평균 |선형-점수| 180 -> |선형+신경망-점수| 63). 데이터와 지금 엔진의 점수 눈금이 달라서 생긴 실패.
- 2차: 지금 게임 설정(lmr2,hm + game 상수 + tuned.json) 으로 50ms 엔진 판 2000판(국면 82만)을 새로 만들어 다시 학습.
  여기서도 평균 |선형-점수| 164 로 1차와 같음 → 눈금 차이는 데이터 탓이 아니라 이 엔진의 성질: **정적 평가와 50ms 탐색 점수의 상관이 0.26**,
  최소제곱 배율 0.095 (탐색 점수가 정적 평가의 약 1/10 크기). 오차는 -86% 줄었지만 신경망이 하는 일은 대부분 선형 평가를 0 쪽으로 줄이는 것
  (탐색해 보면 점수가 거의 0, 깊이도 1~2 얕아짐) → 대국에서 쓸 수 없음. 조용한 국면만 쓰도록 했지만 위협 있는 국면이 0.8% 뿐이라 영향 없음.
- 3차: 탐색 점수를 배율 0.095 로 나눠 선형 평가 눈금에 맞춘 뒤 학습 (줄이는 대신 보정만 배우게).
  - 3차 결과: 검증 오차 -13% (배율 보정 뒤라 줄어드는 폭이 작음). 대국 30ms: 11승 16무 75패 (102판), **Elo -256 (-344 ~ -190)**, SPRT H0 → 기각.
- 결론: 이 게임은 정적 평가로 탐색 점수를 맞히기 어렵고 (상관 0.26), 신경망을 더하면 평가에 잡음이 끼고 탐색도 느려져서 크게 약해짐.
  Texel 실패와 같은 원인. 엔진 실력은 탐색 깊이가 정하고, 평가 상수는 SPSA 3차 값에서 수렴. 코드는 남기고 게임 기본값에는 넣지 않음.
