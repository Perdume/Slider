## 평가 신경망 (아침에 추가로 시도, 실패)
- 엔진 탐색 점수를 정답으로 평가 신경망(NNUE 방식)을 학습. 새 규칙 정보(지금 움직일 말 / 상대가 다음에 움직일 말)도 입력에 넣음.
- 지금 엔진으로 50ms 대국 2000판(82만 국면)을 새로 만들어 학습했지만, **정적 평가와 탐색 점수의 상관이 0.26** 밖에 안 돼서
  신경망이 점수를 0 쪽으로 줄이거나(2차) 잡음을 더하는(3차) 쪽으로 배움.
- 대국 결과: 1차 0승 20패, 3차 로컬 1승 9패, VM SPRT (30ms) 11승 16무 75패, **Elo -256** (판정: 기각).
- 결론: 이 게임에서는 정적 평가로 형세를 맞히는 것 자체가 어렵고(Texel 실패와 같은 원인), 탐색 깊이가 실력을 정합니다.
  엔진은 SPSA 3차 값에서 수렴한 것으로 봅니다. 코드는 남겨 두었고 게임 기본값에는 넣지 않았습니다.
